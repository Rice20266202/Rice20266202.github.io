What does DNS do?

DNS lets a client look up records for a domain name. An address record can tell the client which IP address to contact. A domain may have more than one address.

Why use HTTPS?

HTTPS uses TLS to protect HTTP communication in transit. A browser can check the server certificate, while encryption protects the contents of the exchange.

What makes a useful experiment?

A clear question, a controlled setup, recorded observations, and an explanation that stays within the evidence. Unexpected results are useful observations too.
